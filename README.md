# Закупки без заявок

Срез по 44-ФЗ: государственные закупки, на которые **не подали ни одной заявки**,
и то, что с ними стало дальше — заказчик выложил их заново или ещё нет.

**Сайт:** откройте `index.html` или страницу GitHub Pages этого репозитория.

## Что внутри

Процедуры, завершившиеся с 25 июля по 14 августа 2026 года, разложены на три группы:

| группа | что значит |
|---|---|
| выложены заново, приём идёт | заказчик объявил ту же потребность повторно, заявки принимаются — сюда можно подавать |
| заново пока не выкладывали | потребность висит незакрытой |
| повтор уже закрылся | второй заход тоже прошёл |

Плюс отдельный список активных закупок в тех же товарных нишах и статистика по
заказчикам: доля прекращённых контрактов по последним 50 записям реестра.

## Как это собрано

Источник — открытая часть [zakupki.gov.ru](https://zakupki.gov.ru). Выдача поиска
обходится посуточно с дроблением по цене (ЕИС обрезает любой запрос на 2000 записях),
затем по каждой закупке читается вкладка результатов определения поставщика — там
лежит основание «не подано ни одной заявки».

Отбор: только товары (услуги, работы, лицензии, продукты питания, медицина и ГСМ
исключены), НМЦ от 100 тыс. до 2 млн ₽, поставка в европейскую часть и на Юг.

Повторное объявление ищется по ИНН заказчика с проверкой совпадения предмета:
слова взвешиваются по редкости, а расхождение цены больше чем втрое дисквалифицирует
пару. Совпадения помечены как «точное» (предмет совпал дословно или цена до рубля)
и «проверьте» (опознано по ключевым словам).

## Ограничения

Данные — срез на дату сборки, сроки подачи заявок быстро истекают: сверяйтесь
с карточкой закупки в ЕИС, ссылка есть у каждого номера. Проверены не все протоколы
периода: ЕИС отдаёт около 16 запросов в минуту, полный обход занимает часы.

Контакты должностных лиц заказчиков на сайте не публикуются — они есть в карточке
закупки на zakupki.gov.ru.
